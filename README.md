# Spyro The Dragon App

## Introducción

La aplicación **Spyro The Dragon** es una experiencia interactiva que guía a los usuarios a través de diversas funcionalidades de la aplicación con ayuda de animaciones y efectos visuales atractivos. Los usuarios pueden explorar personajes, mundos y coleccionables, ajustar la configuración según sus preferencias y disfrutar de una guía interactiva que facilita la navegación por la app.

## Características principales

- **Guía interactiva**: Una guía animada que lleva a los usuarios a través de los principales componentes de la aplicación.
- **Navegación intuitiva**: Uso de `NavController` y `BottomNavigationView` para una navegación fácil y fluida.
- **Animaciones atractivas**: Efectos visuales y animaciones para mejorar la experiencia del usuario.
- **Control de música**: Reproduce música y efectos de sonido para mejorar la atmósfera.
- **Preferencias de usuario**: Guardar y recuperar preferencias de usuario para personalizar la experiencia de uso.

## Tecnologías utilizadas

- **Navigation Component**: Manejo de la navegación entre fragmentos.
- **RecyclerView**: Utilizado para mostrar listas de contenido.
- **Glide**: Para cargar y mostrar imágenes de manera eficiente.
- **MediaPlayer**: Reproducción de música y efectos de sonido.
- **ObjectAnimator & AnimatorSet**: Animaciones y transiciones de vista.
- **SharedPreferences**: Para almacenar y recuperar preferencias de usuario.

## Instrucciones de uso

  1. Ejecuta Android Studio.

  2. En el menú superior, selecciona "File > New > Project From Version Control...".

  3. Se abrirá un diálogo donde debes seleccionar "Git" en "Version Control". Luego, introducir este enlace: "https://github.com/rubengitprog/PMDMTarea4RRB" en el apartado de "URL" y, en el apartado "Directory", seleccionar la carpeta donde se guardará el proyecto.

  4. Pulsa en "Clone".

  5. La app está lista para usar.
